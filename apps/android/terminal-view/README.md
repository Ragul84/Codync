# terminal-view (vendored)

Android `View` that renders a `TerminalSession` / `TerminalEmulator`, from
[termux/termux-app](https://github.com/termux/termux-app) `terminal-view` (tag `v0.118.0`),
originally jackpal Android Terminal Emulator.
